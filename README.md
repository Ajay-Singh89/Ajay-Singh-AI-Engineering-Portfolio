# Ajay Singh — Portfolio

A responsive, static portfolio website 

## Preview locally
Open `index.html` in a browser, or serve the folder:
```bash
python -m http.server 8000
```
Then visit http://localhost:8000.

## Publish free with GitHub Pages
1. Create a public GitHub repository, e.g. `ajay-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, `Ajay-Singh-Resume.pdf`, and this README to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for deployment; GitHub will show the public URL in Settings → Pages.

Alternative: drag the folder into Netlify Drop (https://app.netlify.com/drop).
